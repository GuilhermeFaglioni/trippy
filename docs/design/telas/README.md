# Telas de referência (v0.1)

As 35 telas do canvas "Trippy — Telas v0.1", aprovadas pelo Guilherme. Toda tela do app reproduz a sua referência com os componentes de `docs/design-system/` (regras em `docs/agents/ciclo-de-desenvolvimento.md`, "Fidelidade às telas").

- `NN-nome.png`: a tela em 390 × 844 pt, renderizada em 2x.
- `fonte/NN-nome.html`: o HTML original da tela, com o CSS (medidas, cores, espaçamentos) e os dados de exemplo no `<script type="text/x-dc">`. Use para tirar medidas exatas; os PNGs mostram o resultado.

As fontes (Bricolage Grotesque, DM Sans, Noto Sans SC) foram retiradas do HTML; o app já as carrega.
