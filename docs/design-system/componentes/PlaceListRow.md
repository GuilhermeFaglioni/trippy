# PlaceListRow

Linha compacta da lista Lugares (tela 04): miniatura de 52px (paleta `photo-1..4`), nome em até 2 linhas, quem sugeriu em 1 linha, StatusChip e botão "Quero ir" de 52 × 52 (coração + contagem).

- Card `radius-md`, padding 12, gap 12. Sem formulário nem ações extras: tocar na linha abre o lugar.
- O StatusChip abre a folha de dias só para quem monta o roteiro; para membros é só o status.
- "Quero ir" marcado: fundo `terracotta`, coração preenchido.
