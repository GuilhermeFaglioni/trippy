# TabBar

Barra inferior com as abas de uma viagem.

- Abas: Hoje (só em viagem), Roteiro, Lugares, Memórias, Grupo. Ícones Lucide: `sun`, `list-ordered`, `map-pin`, `images`, `users`.
- Aba atual: `aria-current="page"`, `terracotta-text`, negrito, ícone com traço 2.2.
- A volta para Minhas viagens fica no topo da tela (seta + nome da viagem), não na barra.
- Com fonte ampliada acima de 150%, os rótulos quebram em até 2 linhas e a barra cresce; nunca somem.
