# Card

Superfícies de conteúdo: o card comum (`tp-card`) e o card de destaque (`tp-highlight`).

- **Card**: `surface`, `radius-md`, padding 16px, plano. Para listas, seções da tela do lugar, conta.
- **Destaque**: `forest` com texto `on-forest`, `radius-lg`. No máximo um por tela: viagem atual, Próximo lugar, convite, Pronto para viajar. O rótulo (`tp-eyebrow`) fica em `mustard`.
- O consumidor fornece o conteúdo; o card não tem altura fixa.
