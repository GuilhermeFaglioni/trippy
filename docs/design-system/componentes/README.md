# Componentes do design system

Cópia dos componentes do design system do Trippy (artifact "Trippy" no Claude, v0.2). Cada `.md` descreve o uso; `bundle.css` tem as medidas e estados exatos das classes `tp-*`, que a implementação em React Native (`apps/mobile/src/design-system`) reproduz com os tokens de `../tokens.json`.
